Módulo 01

¿Qué es Power Query y para qué se usa en Power BI?

Power Query es el motor de preparación de datos de Microsoft. Se conecta a cientos de fuentes, permite transformar la información con una interfaz gráfica y registra cada acción como un paso que se repite automáticamente al actualizar.

Infografía · Del dato crudo al informe

Proceso ETL

En Power BI, Power Query ocupa la etapa de Extraer, Transformar y Cargar (ETL). Lo que usted limpia aquí es lo que el modelo y los informes utilizan después.

Consolidar reportes

Unir en una sola tabla los archivos mensuales que envían las regionales y centros de formación.

Limpiar bases

Quitar espacios, unificar mayúsculas, corregir tipos de fecha y eliminar duplicados en bases de contratistas o proveedores.

Cruzar información

Combinar la planta de personal con la nómina o el presupuesto con la ejecución, como un BUSCARV sin límites.

Automatizar

Preparar el informe una vez y actualizarlo cada mes con un clic, sin repetir el trabajo manual.

i
¿Dónde lo encuentro? En Power BI Desktop: Inicio › Transformar datos. En Excel: Datos › Obtener datos › Iniciar el Editor de Power Query. También está en los flujos de datos de Power BI Service y Microsoft Fabric. Lo aprendido sirve en todos esos lugares.

Módulo 05

Sintaxis y semántica del lenguaje M

La sintaxis es la forma correcta de escribir una consulta. La semántica es lo que esa escritura significa y cómo la evalúa el motor. Pase el cursor o haga clic sobre cada parte del código.

Anatomía de una consulta

Editor avanzado
let
    Origen = Excel.Workbook(File.Contents("C:\SENA\solicitudes.xlsx")),
    Datos = Origen{[Item="Solicitudes", Kind="Sheet"]}[Data],
    #"Tipo cambiado" = Table.TransformColumnTypes(Datos,
        {{"Valor", Int64.Type}, {"Fecha", type date}}),
    #"Filas filtradas" = Table.SelectRows(#"Tipo cambiado",
        each [Valor] > 500000 and [Estado] = "Aprobado")
in
    #"Filas filtradas"

Infografía · Los pasos son una cadena

Semántica

Cada paso recibe la tabla del paso anterior y entrega una tabla nueva. Ninguno modifica el archivo original.

REGLA 1 · SENSIBLE A MAYÚSCULAS

M distingue mayúsculas

Table.SelectRows funciona; table.selectrows da error. Lo mismo con los nombres de columna: [valor] no es [Valor].

REGLA 2 · INMUTABILIDAD

Los pasos no se sobrescriben

Cada paso crea un valor nuevo. Por eso puede volver a cualquier paso anterior y ver la tabla en ese momento.

REGLA 3 · EVALUACIÓN DIFERIDA

Solo se calcula lo necesario

M evalúa un paso cuando el resultado lo necesita. Un paso que nadie usa no se ejecuta.

REGLA 4 · each Y _

each es una función corta

each [Valor] > 0 equivale a (_) => _[Valor] > 0. Se evalúa una vez por cada fila.

REGLA 5 · TIPOS DE DATOS

Texto no es número

"1500" entre comillas es texto. Hay que cambiar el tipo antes de sumar, comparar o agrupar.

REGLA 6 · PLEGADO DE CONSULTAS

Query folding

Si la fuente es una base de datos, Power Query traduce sus pasos a SQL y deja que el servidor haga el trabajo. Vea el bonus de SQL.

    Ejemplo · Columna condicional
    
          
    Clasificar solicitudes según su valor para priorizar la revisión.
    
          
    Table.AddColumn(#"Tipo cambiado", "Prioridad",
    each if [Valor] >= 2000000 then "Alta"
         else if [Valor] >= 800000 then "Media"
         else "Baja",
    type text)
    
        
    
        
    
          
    Ejemplo · Combinar carpetas mensuales
    
          
    Leer todos los CSV de una carpeta compartida y unirlos en una tabla.
    
          
    let
    Archivos = Folder.Files("C:\SENA\Reportes_2026"),
    SoloCSV  = Table.SelectRows(Archivos, each [Extension] = ".csv"),
    Tablas   = Table.AddColumn(SoloCSV, "Contenido",
                 each Table.PromoteHeaders(Csv.Document([Content], [Delimiter = ";"]))),
    Unidas   = Table.Combine(Tablas[Contenido])
in
    Unidas

        Bonus track
        
    SQL en cinco minutos
    
        
    SQL (Structured Query Language) es el lenguaje estándar para consultar bases de datos. Lo que usted hizo con clics en Power Query, una base de datos lo hace con una sentencia SELECT.
    
      
    

      
    
        
    !
    
        
    Nota importante. SQL es el lenguaje de consultas integrado en prácticamente todos los motores de bases de datos: SQL Server, Oracle, PostgreSQL, MySQL, SQLite, y también en plataformas en la nube como Azure, Microsoft Fabric o BigQuery. Aprender lo básico le permite entender de dónde vienen los datos institucionales y conversar con las áreas de tecnología. Además, cuando Power Query se conecta a una base de datos, traduce muchos de sus pasos a SQL (plegado de consultas).
