Módulo 1 · Conceptos

¿Qué es DAX y para qué se usa en Power BI?

DAX (Data Analysis Expressions) es el lenguaje de fórmulas de Microsoft para Power BI, Power Pivot en Excel y Analysis Services. Con él se crean cálculos sobre un modelo de datos: totales, porcentajes, comparaciones entre periodos y reglas de negocio.

Pasos para conformar una medida

Este orden evita la mayoría de los errores. Aplíquelo cada vez que cree una medida nueva.

1

Formule la pregunta

“¿Qué porcentaje del presupuesto comprometido se ha pagado?”

2

Ubique los datos

Tabla Ejecucion, columnas [Pagado] y [Comprometido].

3

Cree medidas base

Total Pagado y Total Comprometido con SUM.

4

Combine medidas

DIVIDE([Total Pagado], [Total Comprometido])

5

Dé formato

Porcentaje con un decimal; carpeta de visualización.

6

Valide

Compare con un total conocido en una tabla o matriz.

Buenas prácticas

  • Cree una tabla vacía llamada _Medidas para agrupar todas las medidas.
  • Prefiera medidas explícitas a arrastrar columnas numéricas (medidas implícitas).
  • Nombres que entienda cualquier lector: Total Pagado, no m1.
  • Reutilice medidas base dentro de otras medidas.
  • Use VAR para pasos intermedios y comentarios con //.

Errores frecuentes al inicio

  • Usar una columna calculada cuando se necesitaba una medida.
  • Dividir con / y obtener errores cuando el denominador es cero.
  • Escribir texto sin comillas dobles: = Antioquia.
  • Usar inteligencia de tiempo sin una tabla calendario.
  • Escribir funciones en español (SUMA, SI): DAX solo acepta inglés.
Módulo 4 · Forma

Sintaxis: cómo se escribe una fórmula DAX

La sintaxis son las reglas de escritura. Pase el cursor o toque cada parte para ver su función.

Total Pagado Antioquia = CALCULATE( SUM( 'Ejecucion'[Pagado] ), Ejecucion[Regional] = "Antioquia" )

Reglas esenciales

ElementoCómo se escribe
TablaEjecucion o 'Ejecución 2025' (comillas simples si tiene espacios o tildes)
ColumnaEjecucion[Pagado] siempre con su tabla
Medida[Total Pagado] solo entre corchetes
Texto"Antioquia" entre comillas dobles
FechaDATE(2025, 12, 31)
Comentario// una línea · /* varias */
VariablesVAR x = ... RETURN x

Separador de argumentos: Power BI usa la coma por defecto. Si su equipo está configurado para usar punto y coma, cámbielo en Archivo › Opciones › Configuración regional o escriba según lo que muestre el editor.

Transición de contexto
Cuando una medida se usa dentro de un iterador (por ejemplo SUMX), CALCULATE convierte la fila actual en un filtro. Por eso [Total Pagado] dentro de SUMX devuelve el valor de esa fila.

    
BLANK no es cero
DAX devuelve BLANK() cuando no hay datos. Los visuales ocultan esas filas. DIVIDE devuelve BLANK al dividir por cero en lugar de un error.

    
Tipos de datos
Número entero, decimal, decimal fijo (moneda), fecha/hora, texto, booleano. Sumar una columna de texto genera error: revise el tipo en Power Query.

Glosario rápido

    

      
MedidaCálculo que se evalúa al consultar, según los filtros del informe.

      
Contexto de filtroConjunto de filtros activos (segmentaciones, filas del visual, CALCULATE) al evaluar una medida.

      
Contexto de filaLa fila que se está evaluando en una columna calculada o un iterador.

      
IteradorFunción terminada en X (SUMX, AVERAGEX) que recorre una tabla fila por fila.

      
Tabla calendarioTabla con una fila por fecha, necesaria para la inteligencia de tiempo.

      
Medida implícitaAgregación automática al arrastrar una columna numérica a un visual. Se recomienda reemplazarla por medidas explícitas.
