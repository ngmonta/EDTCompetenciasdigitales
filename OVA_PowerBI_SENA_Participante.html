Siguiente: ¿Qué es Power BI?

¿Qué es Power BI?

Power BI es la plataforma de inteligencia de negocios (BI) de Microsoft. Reúne datos de muchas fuentes, los transforma en un modelo coherente y los presenta en informes y tableros interactivos que se actualizan solos.

Piense en Power BI como una cadena de producción: entra información dispersa (archivos de Excel, bases de datos, SharePoint, sistemas como SECOP o el aplicativo de PQRS) y sale una vista única y confiable que cualquier persona autorizada puede consultar desde el navegador o el celular.

Infografía: el flujo de trabajo en Power BI

Los componentes de la plataforma

Gratis · Windows

Power BI Desktop

Aplicación de escritorio donde se conecta, transforma, modela y diseña. Es la herramienta principal de este taller. Genera archivos .pbix (o carpetas de proyecto .pbip).

Nube · navegador

Power BI Service

Sitio web app.powerbi.com donde se publican informes, se crean paneles (dashboards), áreas de trabajo y aplicaciones, y se programan actualizaciones de datos.

iOS · Android

Power BI Mobile

Aplicaciones para consultar tableros desde el celular, recibir alertas de datos y compartir anotaciones.

Conectividad

Puerta de enlace (gateway)

Software que conecta la nube con datos que viven en servidores o carpetas internas, para que la actualización programada funcione.

Informes paginados

Power BI Report Builder

Diseña informes con formato de impresión (actas, certificados, listados oficiales) con muchas páginas y encabezados fijos.

Plataforma de datos

Microsoft Fabric y Copilot

Power BI hoy forma parte de Microsoft Fabric, que integra almacenamiento, ingeniería de datos e IA. Copilot puede sugerir visuales, medidas y resúmenes cuando la licencia de la entidad lo habilita.

¿Para qué sirve en la gestión administrativa del SENA?

Sirve para pasar de reportar datos a explicar resultados. Estos son casos de uso directos para las áreas de apoyo de un centro de formación o una regional.

Beneficios concretos

Menos tiempo armando informes

El informe mensual que hoy toma un día de copiar y pegar se actualiza con un clic, porque Power Query recuerda cada paso de limpieza.

Una sola versión de la verdad

Todos consultan el mismo modelo publicado; se acaban los archivos “final_v3_definitivo.xlsx”.

Alertas tempranas

Semáforos y alertas de datos avisan cuando un rubro se rezaga o una PQRSF está por vencer.

Transparencia y rendición de cuentas

Tableros claros para comités, auditorías y espacios de rendición de cuentas, con datos trazables hasta la fuente.

Cuidado con los datos personales

Antes de publicar, revise que el informe cumpla la Ley 1581 de 2012 (protección de datos personales) y las políticas de seguridad de la información del SENA. No publique cédulas, teléfonos ni datos sensibles; use la seguridad por fila (RLS) para restringir lo que ve cada usuario.

Instalación de Power BI Desktop

Power BI Desktop es gratuito y solo funciona en Windows. En equipos institucionales, la instalación puede requerir permisos de administrador: coordine con la mesa de ayuda de TI antes de la sesión 1.

En Mac no existe versión nativa: se usa una máquina virtual con Windows o se trabaja solo en Power BI Service desde el navegador.

Opción A (recomendada): Microsoft Store

  1. Abra Microsoft Store desde el menú Inicio de Windows.
  2. Busque “Power BI Desktop” y verifique que el editor sea Microsoft Corporation.
  3. Pulse Obtener o Instalar. La descarga pesa varios cientos de MB.
  4. Abra la aplicación desde Inicio. La Store la mantendrá actualizada cada mes de forma automática.

Opción B: instalador ejecutable (.exe)

  1. Ingrese al Centro de descargas de Microsoft (enlace en la sección Cibergrafía) y pulse Descargar.
  2. Elija PBIDesktopSetup_x64.exe para equipos de 64 bits.
  3. Ejecute el instalador, acepte la licencia, deje la ruta por defecto y marque “Crear acceso directo en el escritorio”.
  4. Finalice y abra Power BI Desktop. Con esta opción, las actualizaciones mensuales se instalan manualmente.

No mezcle ambas versiones

Si ya tiene instalada la versión .exe y quiere pasar a la de Microsoft Store, desinstale primero la anterior desde Configuración › Aplicaciones para evitar conflictos.

  2. Inicio de sesión: opcional en Desktop. Inicie con su cuenta @sena.edu.co solo si va a publicar.
  3. Idioma: Power BI toma el idioma de Windows. Puede cambiarlo en Archivo › Opciones y configuración › Opciones › Configuración regional.

AnteriorSiguiente: Modelado

Modelado de datos: el esquema en estrella

Un buen modelo separa lo que se mide (hechos) de cómo se describe (dimensiones). Así, un solo filtro de “Regional” afecta contratos, presupuesto y PQRSF a la vez.

Tablas de hechos

Registran eventos o transacciones: cada contrato, cada PQRSF, cada movimiento presupuestal. Tienen muchas filas y columnas numéricas que se suman o cuentan.

Tablas de dimensión

Describen el contexto: quién, dónde, cuándo, qué. Tienen pocas filas y una clave única (CentroID, Date). Se usan en segmentadores y ejes.

Relaciones: lo que hay que revisar

PropiedadValor habitualSignificado
CardinalidadUno a varios (1:*)Un centro tiene muchos contratos.
Dirección del filtro cruzadoÚnicaLa dimensión filtra a los hechos. Use “Ambas” solo con razón clara.
Activa / inactivaActivaSolo una relación activa entre dos tablas; las demás se activan en DAX con USERELATIONSHIP.
  1. Vaya a la vista Modelo (tercer icono de la barra izquierda).
  2. Arrastre Centros[CentroID] sobre Contratos[CentroID].
  3. Confirme en el cuadro de diálogo: cardinalidad Varios a uno, filtro Único, relación activa.
  4. Oculte las claves en las tablas de hechos (clic derecho › Ocultar en la vista de informe) para que nadie las use por error.

Cuando dos tablas de hechos comparten una columna

Apropiacion y EjecucionPresupuestal tienen ambas la columna Rubro. No las relacione entre sí: cree una dimensión Rubros con Rubros = DISTINCT ( Apropiacion[Rubro] ) y relaciónela 1 → * con cada una. Así un solo filtro de rubro afecta a las dos (Ejemplo 3).

AnteriorSiguiente: DAX

DAX: calcular indicadores

DAX (Data Analysis Expressions) es el lenguaje de fórmulas del modelo. Se parece a Excel, pero trabaja con tablas y columnas completas y responde al contexto de los filtros.

Medida

Se calcula en el momento según los filtros activos. Úsela para totales, promedios, porcentajes e indicadores. Es la opción preferida.

Total Contratado = SUM(Contratos[ValorContrato])

Columna calculada

Se calcula fila por fila al actualizar y ocupa memoria. Úsela para clasificar o para usar en ejes y segmentadores.

Rango = IF(Contratos[ValorContrato] > 100000000, "Mayor", "Menor")

Tabla calculada

Crea una tabla nueva con una fórmula. Ideal para la tabla Calendario.

Calendario = CALENDAR(DATE(2025,1,1), DATE(2025,12,31))

Publicar, compartir y mantener actualizado

Un informe solo genera valor cuando llega a quien decide. Power BI Service es el lugar donde se publica, se protege y se actualiza.

Pasos para publicar

  1. Guarde el archivo .pbix con un nombre claro, por ejemplo Tablero_Contratacion_CF03_2025.pbix.
  2. Inicie sesión con su cuenta institucional (esquina superior derecha de Desktop).
  3. Pulse Inicio › Publicar y elija el área de trabajo de destino (evite “Mi área de trabajo” para contenido del equipo).
  4. Abra el enlace que aparece al terminar para ver el informe en app.powerbi.com.
  5. Configure la actualización programada en el modelo semántico: credenciales, puerta de enlace si los datos están en la red interna, y frecuencia.
  6. Comparta mediante el botón Compartir, dando acceso al área de trabajo o, mejor, publicando una aplicación para los usuarios finales.

Los nombres de botones, pestañas y menús aparecen así: Inicio › Libro de Excel. El signo › significa “luego haga clic en”. Cuando termine un paso, marque la casilla Hecho: su avance queda guardado en este navegador.
