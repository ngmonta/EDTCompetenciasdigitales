Que los reportes se consoliden solos

Cada mes llegan archivos de varias dependencias con el mismo formato, y alguien los copia y pega uno por uno. En este tema aprenderá a construir ese consolidado una sola vez con Power Query y a dejarlo listo para actualizarse con un clic, con el formato final aplicado por una macro.

Contexto

¿Qué son los Fundamentos de Excel intermedio?

Son el conjunto de habilidades que permiten pasar de usar Excel como una hoja para escribir datos a usarlo como una herramienta de análisis y gestión. Un usuario intermedio organiza la información en tablas estructuradas, usa funciones lógicas y de búsqueda, resume con tablas dinámicas, controla la calidad de los datos y, en este último tema, automatiza las tareas que se repiten cada mes.

Subtema 10.1

Qué es Power Query

Power Query es el motor de Excel para obtener datos de distintas fuentes, transformarlos (limpiar, dividir, unir) y cargarlos en una hoja, sin escribir fórmulas. Cada acción que haga con el mouse queda guardada como un paso, y todos los pasos se repiten automáticamente cada vez que actualice.

1

Obtener (Extract)

Conectarse a un archivo, una carpeta, un CSV o una tabla. Los datos originales no se modifican.

Datos › Obtener datos
2

Transformar (Transform)

Quitar filas, dividir columnas, reemplazar valores, cambiar tipos, anular dinamización, combinar tablas.

Editor de Power Query
3

Cargar (Load)

Enviar el resultado a una tabla, a una tabla dinámica o solo como conexión. Se actualiza con un clic.

Cerrar y cargar

Dónde está en Excel

  1. Pestaña Datos, grupo Obtener y transformar datos.
  2. Obtener datos despliega las fuentes: Desde un archivo, Desde una base de datos, Desde otras fuentes.
  3. Al elegir una fuente se abre el Editor de Power Query: a la derecha verá el panel Pasos aplicados; arriba, la barra de fórmulas con el código M de cada paso (actívela en Vista › Barra de fórmulas).
  4. Para volver a una consulta: Datos › Consultas y conexiones y doble clic sobre ella.
Idea clave: Power Query no cambia los archivos de origen. Lee, transforma y carga una copia. Por eso es seguro trabajar sobre los reportes oficiales.

El lenguaje M, sin miedo

Cada paso que hace con el mouse se escribe en un lenguaje llamado M. No necesita aprenderlo para usar Power Query, pero reconocerlo ayuda a entender qué hace cada paso. Así se ve un paso de «Quitar filas superiores»:

M
= Table.Skip(Origen, 4)

Se lee: «a partir del paso Origen, salta las 4 primeras filas». Cada paso usa el resultado del anterior, como una receta.

Subtema 10.2

Fuentes de datos

Power Query se conecta a muchas fuentes. Para el trabajo administrativo, cuatro cubren casi todo: libros de Excel, archivos CSV, carpetas con reportes y archivos exportados de los aplicativos institucionales.

Libro de Excel

Datos › Obtener datos › Desde un archivo › Desde un libro de Excel

Puede elegir una hoja o una tabla con nombre. Prefiera tablas (Ctrl+T): sus encabezados son estables.

Archivo de práctica: Catalogo_Elementos.xlsx (tabla tblCatalogo)

Texto o CSV

Datos › Obtener datos › Desde un archivo › Desde texto/CSV

Revise en la vista previa el Origen del archivo (codificación, p. ej. 1252: Europeo occidental) y el Delimitador (punto y coma o coma). Si salen símbolos raros en las tildes, cambie la codificación.

Archivo de práctica: Exportado_Aplicativo_Inventario.csv

Carpeta completa

Datos › Obtener datos › Desde un archivo › Desde una carpeta

Lee todos los archivos de una carpeta y los combina con el botón Combinar y transformar datos. Todo archivo nuevo que se guarde allí entra en la próxima actualización.

Archivo de práctica: Carpeta Reportes_Dependencias

Reportes de aplicativos

Exportar a Excel o CSV desde el aplicativo › conectar como archivo o carpeta

Los exportes suelen traer filas de título, fecha de generación, filas en blanco y una fila TOTAL. Power Query las quita con pasos que se repiten cada mes.

Archivo de práctica: Cualquiera de los 12 reportes de dependencias

Paso a paso

Ejemplo 1: importar un CSV exportado de un aplicativo

  1. Abra un libro nuevo. Datos › Obtener datos › Desde un archivo › Desde texto/CSV y elija Exportado_Aplicativo_Inventario.csv.
  2. En la vista previa verifique Origen del archivo: 1252 Europeo occidental (Windows) y Delimitador: Punto y coma. Las tildes de «Descripción» deben verse bien.
  3. Pulse Transformar datos (no Cargar) para abrir el Editor.
  4. Columna Estado: Transformar › Formato › Poner En Mayúsculas Cada Palabra. «BUENO» y «Bueno» quedan iguales.
  5. Columna Valor: Transformar › Reemplazar valores, buscar . reemplazar por nada. Luego cambie el tipo a Número entero con el icono ABC/123 del encabezado.
  6. Columna Fecha ingreso: clic en el icono de tipo › Usar configuración regional › Fecha › Español (Colombia). Así 03/04/2021 se lee como 3 de abril.
  7. Inicio › Cerrar y cargar. Obtendrá una tabla limpia de 40 bienes.
Paso a paso

Ejemplo 2: conectar una carpeta completa

  1. Copie la carpeta Reportes_Dependencias en una ruta corta, por ejemplo C:\Taller_PQ\.
  2. Datos › Obtener datos › Desde un archivo › Desde una carpeta › Examinar › seleccione la carpeta › Abrir.
  3. Verá una lista con 12 archivos (Name, Extension, Date modified…). Pulse Combinar › Combinar y transformar datos.
  4. En «Combinar archivos», con Archivo de ejemplo: Primer archivo, seleccione la hoja Reporte y Aceptar.
  5. Power Query crea la carpeta Archivos auxiliares con «Transformar archivo de ejemplo». Lo que limpie allí se aplica a todos los archivos. Esto se trabaja en el taller.
Trabajo colaborativo: si la carpeta está en una biblioteca de SharePoint u OneDrive institucional compartida con las dependencias, cada una guarda allí su reporte y usted solo actualiza. Use Obtener datos › Desde un archivo › Desde una carpeta de SharePoint con la dirección del sitio.
Reglas para que una carpeta funcione: todos los archivos con la misma estructura (mismos encabezados y nombre de hoja), sin otros archivos en la carpeta, y nombres de archivo con un patrón fijo (por ejemplo 2026-07_Talento Humano.xlsx) porque de ahí se extraen el mes y la dependencia.

Pasos aplicados

    ¿Por qué anular dinamización?

    Los reportes suelen llegar anchos: una columna por semana o por mes. Se ven bien impresos, pero no sirven para resumir: no puede filtrar «Semana» ni hacer una tabla dinámica por semana.

    Anular dinamización convierte esas columnas en dos: Atributo (el nombre de la columna: Semana 1…) y Valor (la cantidad). La tabla queda larga, con un dato por fila.

    Consejo: seleccione las columnas que no cambian (Código, Elemento, Unidad) y use Anular dinamización de otras columnas. Si un mes llega una «Semana 5», se incluye sola.

    Práctica guiada

    Ejemplo 3: Ejemplo_Transformaciones.xlsx

    La tabla tblAtenciones tiene «Dependencia - Responsable» en una sola columna, meses en columnas y valores «N/A».

    1. Clic dentro de la tabla › Datos › Desde la tabla o rango.
    2. Columna «Dependencia - Responsable» › Transformar › Dividir columna › Por delimitador › Personalizado: - (espacio, guion, espacio) › En el delimitador situado más a la izquierda. Renombre: Dependencia y Responsable.
    3. Seleccione Ene a Jun (clic en Ene, Mayús + clic en Jun) › Transformar › Reemplazar valores: «N/A» por null.
    4. Seleccione Dependencia y Responsable › clic derecho › Anular dinamización de otras columnas. Renombre Atributo → Mes y Valor → Atenciones.
    5. Cambie el tipo de Atenciones a Número entero y Cerrar y cargar.
    Para pensar: al anular dinamización, las celdas vacías (null) desaparecen. ¿Es correcto para el informe, o debería reemplazarlas por 0 antes? Depende: 0 significa «no hubo atenciones»; null significa «no se reportó».

    Anexar y combinar consultas

    Hay dos formas de unir tablas y conviene no confundirlas. Anexar pone una tabla debajo de la otra (más filas). Combinar cruza dos tablas por una columna común y trae columnas nuevas (como BUSCARV).

    Más filas

    Anexar consultas

    Inicio › Anexar consultas › Anexar consultas como nuevas. Úselo cuando las tablas tienen las mismas columnas. La conexión a carpeta del taller es un anexar automático de todos los archivos.

    Más columnas

    Combinar consultas

    Inicio › Combinar consultas. Elija la columna común en cada tabla (Cédula, Código) y el tipo de combinación. Luego expanda las columnas que necesita con el icono ↔ del encabezado.

    Ejemplo 4: Ejemplo_Anexar_Combinar.xlsx

    1. Cargue cada tabla como consulta: clic en la tabla de la hoja Julio › Datos › Desde la tabla o rango › Cerrar y cargar en › Solo crear conexión. Repita con Agosto y Funcionarios.
    2. Datos › Obtener datos › Combinar consultas › Anexar › Dos tablas: tblJulio y tblAgosto › Aceptar. Resultado: 20 trámites.

    6. Cerrar y cargar. Ahora puede hacer una tabla dinámica de tiempo de respuesta por dependencia.

    Subtema 10.5

    Macros grabadas

    Una macro es una serie de acciones guardadas que Excel puede repetir. La grabadora de macros registra lo que usted hace (clics, formatos, selecciones) y lo convierte en código VBA, sin programar.

    1 · Preparar

    Activar Programador

    Archivo › Opciones › Personalizar cinta de opciones › marcar Programador.

    2 · Grabar

    Grabar macro

    Programador › Grabar macro (o Vista › Macros). Nombre sin espacios.

    3 · Ejecutar

    Ejecutar

    Alt+F8 › elegir la macro › Ejecutar, o con su atajo.

    4 · Botón

    Asignar a botón

    Insertar › Formas › dibujar › clic derecho › Asignar macro.

    Paso a paso

    Grabe la macro «FormatoFinal» del informe

    1. Abra el libro del taller con la tabla tblConsolidado cargada en la hoja Consolidado. Haga clic en la celda A1.
    2. Programador › Grabar macro. Nombre: FormatoFinal. Método abreviado: Ctrl+Mayús+F. Guardar macro en: Este libro. Descripción: «Formato institucional del consolidado». Aceptar.
    3. Seleccione la fila de encabezados de la tabla › relleno verde SENA (Más colores › Personalizado › RGB 57, 169, 0), fuente blanca y negrita.
    4. Seleccione las columnas Valor unitario y Valor total › Inicio › Número › Moneda sin decimales.
    5. Columna Mes › Formato de celdas › Personalizada mmm-aaaa.
    6. Seleccione las columnas A:J › Inicio › Formato › Autoajustar ancho de columna. Clic en A2 › Vista › Inmovilizar › Inmovilizar fila superior.
    7. Programador › Detener grabación. Pruebe: quite el formato y ejecute con Alt+F8.
    8. Hoja Informe › Insertar › Formas › Rectángulo redondeado › escriba «Actualizar y formatear» › clic derecho › Asignar macro › FormatoFinal.
    9. Archivo › Guardar como › Tipo: Libro de Excel habilitado para macros (*.xlsm). Si guarda como .xlsx, la macro se pierde.

    Lo que la grabadora escribe

    Abra Alt+F11 y vea el módulo. Note el rango fijo I2:J413: cuando octubre agregue filas, la macro no les dará formato. Es la principal limitación de las macros grabadas.

    VBA
    Sub FormatoFinal()
    Range("A1:J1").Select
    With Selection.Interior
        .Pattern = xlSolid
        .Color = 43321
    End With
    Selection.Font.Bold = True
    Range("I2:J413").Select
    Selection.NumberFormat = "$ #,##0"
    Columns("A:J").EntireColumn.AutoFit
End Sub

    Solución sin programar: aplique los formatos de número a las columnas completas (clic en la letra de la columna) mientras graba, o dé el formato una vez a la tabla: Power Query lo conserva al actualizar.

    Seguridad de macros

    • Una macro puede borrar, enviar o modificar archivos. Por eso Excel las deshabilita por defecto y muestra la barra amarilla «Habilitar contenido».
    • Configuración: Archivo › Opciones › Centro de confianza › Configuración del Centro de confianza › Configuración de macros. Recomendado: Deshabilitar todas las macros con notificación.
    • Los archivos descargados de Internet o del correo traen la «marca de la Web» y Microsoft 365 bloquea sus macros (barra roja). Solo si confía en el origen: clic derecho al archivo › Propiedades › Desbloquear.
    • Ubicaciones de confianza: una carpeta donde las macros se ejecutan sin preguntar. Úsela solo para sus propios archivos y siguiendo la política del área de TI.
    • Nunca habilite macros de un archivo que no esperaba recibir, aunque parezca institucional.
    En el SENA: consulte con la mesa de servicios de TI antes de cambiar la configuración del Centro de confianza en un equipo institucional.

    Retroalimentación

    ¿Cuándo conviene automatizar y qué riesgos implica?

    Automatizar ahorra tiempo, pero no siempre conviene y siempre implica riesgos. Use la calculadora con un reporte real de su dependencia y luego responda las preguntas de discusión.

    Calculadora

    ¿Conviene automatizar este reporte?

    Cuándo conviene automatizar

    • La tarea se repite con frecuencia (semanal, mensual) y siempre con los mismos pasos.
    • Los archivos de origen tienen una estructura estable.
    • Hay muchos archivos o muchas filas, y el riesgo de error humano es alto.
    • Otra persona debe poder repetir el proceso sin depender de usted.

    Riesgos y cómo controlarlos

    • Cambio de estructura: si una dependencia cambia un encabezado, la consulta falla o, peor, carga datos incompletos sin avisar. Control: totales de verificación.
    • Confianza ciega: «lo hizo Excel» no garantiza que esté bien. Revise conteos y sumas cada vez.
    • Dependencia de una persona: documente los pasos y deje el archivo en una ubicación compartida.
    • Macros maliciosas: habilite solo macros propias o de origen verificado.
    • Datos personales: la Ley 1581 de 2012 exige proteger los datos personales; no cargue cédulas o salarios en carpetas abiertas.
    • Rutas locales: una consulta a C:\ no funciona en el equipo de otra persona. Use rutas compartidas o la hoja Parametros.
    Discusión

    Preguntas para la socialización

    1. ¿Qué reporte de su dependencia automatizaría primero y por qué?
    2. ¿Qué pasaría si en noviembre una dependencia envía el reporte con la hoja llamada «Hoja1»? ¿Cómo lo detectaría?
    3. ¿Quién más debería saber cómo funciona su consolidado, y dónde dejaría la documentación?
    4. ¿Qué tarea de su trabajo no conviene automatizar? Explique.

    Glosario

    Términos clave

    Actualizar todo
    Comando (Datos › Actualizar todo, Ctrl+Alt+F5) que vuelve a ejecutar todas las consultas y tablas dinámicas del libro.
    Anexar consultas
    Unir tablas con las mismas columnas una debajo de otra. Aumenta el número de filas.
    Anular dinamización
    Convertir columnas en filas (unpivot). Pasa de una tabla ancha a una larga.
    Anti izquierda
    Tipo de combinación que devuelve las filas de la tabla izquierda sin coincidencia en la derecha.
    Archivo de ejemplo
    Archivo que Power Query usa como modelo al combinar una carpeta. Sus pasos se aplican a todos.
    Botón de macro
    Forma o control al que se asigna una macro para ejecutarla con un clic.
    Centro de confianza
    Configuración de seguridad de Office que define cómo se tratan macros, complementos y ubicaciones.
    Combinar consultas
    Cruzar dos tablas por una o más columnas comunes para traer columnas de una a otra (merge).
    Consulta
    Conjunto de pasos guardados que obtiene y transforma datos de un origen.
    CSV
    Archivo de texto con valores separados por coma o punto y coma. Formato habitual de exportación de aplicativos.
    Delimitador
    Carácter que separa partes de un texto, como «_», « - » o «;».
    Editor de Power Query
    Ventana donde se aplican y revisan las transformaciones de una consulta.
    ETL
    Extraer, transformar y cargar: el ciclo de trabajo de Power Query.
    Externa izquierda
    Combinación que conserva todas las filas de la izquierda y trae las coincidencias de la derecha.
    Grabadora de macros
    Herramienta que registra acciones del usuario y las convierte en código VBA.
    Lenguaje M
    Lenguaje en el que Power Query guarda cada paso de una consulta.
    Macro
    Secuencia de instrucciones que automatiza tareas en Excel.
    Marca de la Web
    Etiqueta que Windows pone a archivos descargados; hace que Office bloquee sus macros.
    null
    Valor vacío en Power Query. No es lo mismo que 0 ni que un texto vacío.
    Pasos aplicados
    Panel del Editor que lista, en orden, las transformaciones de la consulta.
    Solo crear conexión
    Opción de carga que guarda la consulta sin escribir datos en una hoja; útil para tablas auxiliares.
    Tabla de Excel
    Rango con formato de tabla (Ctrl+T) que tiene nombre y crece automáticamente.
    Tipo de datos
    Clase de valor de una columna: texto, número entero, decimal, fecha, moneda.
    Ubicación de confianza
    Carpeta en la que Excel ejecuta macros sin preguntar.
    VBA
    Visual Basic para Aplicaciones: el lenguaje de las macros de Office.
    .xlsm
    Formato de libro de Excel habilitado para macros.
